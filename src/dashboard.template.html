Seats changing hands

A flip is a race whose winner's party differs from the party holding the seat now. Called races are separated from projections, which can still reverse.

Systemic polling error

Result margin minus polling average, in points. Positive = the result ran more Republican than the polls.

Feed coverage & manual overrides

Live results come from civicAPI. State election-night feeds (Clarity/Scytl) block cross-origin requests, so a static page cannot read them directly — use the override box for any race the feed has not filled.
Manual override — paste race_key, margin_r_minus_d, percent_reporting per line

Example: senate/GA, -1.4, 88 marks Georgia as D+1.4 with 88% in. Overrides win over the feed and are tagged in the table. They live in this browser only.

Recorded history

Every successful refresh is recorded so the board can show how a race moved, not only where it stands. This is the browser's own copy and is lost if site data is cleared — for a durable archive run node scripts/record.mjs alongside, which writes NDJSON to data/snapshots/ and keeps going if this tab does not.
